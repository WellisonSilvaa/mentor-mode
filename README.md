# 🎓 Antigravity Mentor Mode

> **Transforme sua IA de uma simples "copiadora de código" em uma Mentora de Elite.**

O **Mentor Mode** é uma extensão pedagógica para o assistente de IA Antigravity. Ele implementa a metodologia de *Scaffolding Progressivo*, garantindo que você aprenda cada linha de código que o assistente sugere.

Idealizado pelo desenvolvedor **Wellison** para combater o vício em delegar tarefas e promover o crescimento real de carreira.

---

## 🚀 Instalação Rápida

### 1. Instalação Global (Comandos e Regras)
Instale os comandos `/mentor-` e as regras de comportamento no seu sistema:
```bash
npx antigravity-mentor-mode install
```

### 2. Inicialização do Projeto (Acompanhamento)
Crie a pasta de memória e rastreio dentro do seu projeto atual:
```bash
npx antigravity-mentor-mode init
```

---

## 🧠 Como Funciona? (Os 4 Níveis)

A IA adapta o nível de ajuda conforme você evolui em cada tecnologia:

1.  **Nível 4 (Aprendiz):** Você não conhece o assunto. A IA explica com analogias e exemplos comentados.
2.  **Nível 3 (Praticante):** Você conhece o conceito. A IA fornece o **esqueleto** e você preenche a lógica.
3.  **Nível 2 (Autônomo):** Você faz tudo do zero e a IA atua como **revisora crítica**.
4.  **Nível 1 (Mestre):** Você já domina. A IA atua apenas como consultora sob demanda.

## 🔑 Comandos Principais

| Comando | O que faz |
| :--- | :--- |
| `/mentor-ajuda` | Exibe o guia rápido de comandos. |
| `/mentor-aprender` | Solicita uma aula teórica sobre um tópico. |
| `/mentor-esqueleto` | Pede a estrutura de código para você completar. |
| `/mentor-revisar` | Pede um Code Review detalhado do que você escreveu. |
| `/mentor-progresso` | Exibe seu quadro de habilidades (Skills Tracker). |
| `/mentor-porquê` | Explica a decisão arquitetural por trás de um código. |

---

## 📂 A Pasta `.mentor/`

Ao rodar o comando `init`, seu projeto ganha superpoderes de memória:

*   **`SESSION.md`**: Diário automático de progresso. "Onde paramos?" nunca mais será uma dúvida.
*   **`SKILLS.md`**: Seu currículo visual crescendo conforme você pratica.
*   **`CONCEPTS.md`**: Seu dicionário pessoal de conceitos explicados pela IA.
