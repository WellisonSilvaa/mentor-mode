# 🎓 Antigravity Mentor Mode

O **Mentor Mode** é uma extensão para o assistente de IA Antigravity, projetada para transformar a IA de uma simples "executora de código" em uma **mentora ativa**.

Este sistema foi idealizado pelo desenvolvedor **Wellison** para combater o vício em delegar tarefas e promover o aprendizado contínuo através de *Scaffolding Progressivo*.

## 🚀 Como Instalar

Para instalar as habilidades e regras globais no seu ambiente Antigravity, rode:

```bash
npx antigravity-mentor-mode install
```

## 🧠 Como Funciona

O Mentor Mode utiliza 4 níveis de suporte que se adaptam ao seu conhecimento:

1. **Nível 4 (Aprender):** Explicações profundas com analogias.
2. **Nível 3 (Esqueleto):** A IA dá a estrutura e você preenche a lógica.
3. **Nível 2 (Tentar):** Você faz tudo e a IA revisa.
4. **Nível 1 (Dominado):** A IA só intervém se chamada.

## 🔑 Comandos Principais

- `/mentor-ajuda`: Lista todos os comandos.
- `/mentor-aprender`: Teoria e conceitos.
- `/mentor-esqueleto`: Estrutura guiada.
- `/mentor-revisar`: Code Review detalhado.
- `/mentor-progresso`: Ver suas habilidades evoluindo.
